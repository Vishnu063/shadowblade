# Anatomical head source

The head topology in `head.obj` is a cropped, adapted subset of MakeHuman's graphical base mesh, released under CC0. No MakeHuman application code is included or used in the game. The project code, clothing, armour, skeleton, Warden and environment are authored separately.

Source asset: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj

License statement: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md

Project license explanation: https://www.makehumancommunity.org/about/license.html

Retrieved 27 October 2026. The upstream `base.obj` header explicitly states the September 2020 CC0 release; a copy of the upstream license explanation is retained in `LICENSE.md`. The source is reduced to body-group faces above Y=6.0; the build script rescales/positions it, regenerates UVs, adds pigmentation and binds it to Kael's head bone.
